# Windows 自动输入效率工具

一个从实际需求出发，通过 ChatGPT/Codex 协作完成的 Windows 桌面工具。用户可先载入长文本，再把内容以可控节奏输入当前窗口，适用于演示、重复录入、表单测试等场景。

## AI 落地过程

- 将“自动输入长文本”的模糊想法拆解为文本载入、输入控制、节奏设置、状态反馈和异常边界。
- 通过自然语言与 ChatGPT/Codex 协作完成产品交互、技术方案、代码迭代、测试和使用文档。
- 从需求出发做成可直接运行的 Windows 工具，而不是停留在提示词或概念方案。

## 核心功能

- 文本预检：载入前检查不支持的字符，避免输入过程中断。
- 速度调节：支持 1-200 字符/秒。
- 节奏控制：标点、换行自动增加停顿。
- 快速启停：点击目标输入框后，可用鼠标中键或界面按钮开始/停止。
- 状态反馈：显示载入状态、输入进度和异常信息。
- 本地运行：采用 Windows Unicode 输入，不占用剪贴板，不上传文本。

## 使用方法

1. 双击 `start.bat`。
2. 把需要输入的文本粘贴到工具窗口。
3. 点击“加载”，完成文本预检。
4. 点击目标软件的输入位置。
5. 按鼠标中键或点击“开始”，3 秒后开始输入；再次操作可停止。

## 技术实现

- PowerShell + Windows Forms 构建桌面界面。
- 通过 Windows `SendInput` API 发送 Unicode 字符、回车和 Tab。
- 使用全局鼠标钩子监听鼠标中键。
- 对 emoji 等基础多文种平面之外的字符进行预检提示。

## 当前边界

- 仅支持 Windows。
- 部分受保护的软件或网页可能拦截模拟输入。
- 当前采用 Unicode 直接输入，不控制第三方输入法候选词。
