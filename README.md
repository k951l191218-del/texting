# 真人节奏打字工具

这是一个 Windows 小工具。把文章粘贴进去后，点击你要输入文字的位置，按 `F12`，工具会在当前光标处逐字输入内容，并加入随机停顿，让节奏更像真人打字。

## 使用方法

1. 双击 `start.bat`。
2. 把文章粘贴到窗口的大文本框。
3. 点击目标软件里的输入位置。
4. 按 `F12`，等待 3 秒后开始打字。
5. 打字过程中再次按 `F12` 可以停止。

## 默认节奏

- 单字间隔：160-290 毫秒
- 标点后额外停顿：350-1000 毫秒
- 换行后额外停顿：600-1600 毫秒
- 偶尔会随机多停一下，模拟思考或手速波动

## 关于“拼音输入”

当前版本采用 Windows Unicode 键入，效果是在光标处直接出现中文文本，稳定性比真实调用输入法候选词更高。真实“逐个拼音字母 + 候选词确认”的模式需要额外的汉字转拼音词库和输入法候选控制，后续可以在这个版本上继续加。
